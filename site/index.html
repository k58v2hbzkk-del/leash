    Agents never hold your keys

    An agent doesn't place orders. It sends an intent to Leash: coin, side, leverage, size and a reason. Leash is the only thing that can trade, and it checks your rules first.

    Your glasses only ever see one card at a time: who wants what, how much of your account it uses, how far it is from liquidation, and which of your lines it crossed.

    Plug in your own agent

    Any agent, one endpoint

    An LLM, a bot or a script. It gets a Leash key, never an exchange key.

    # your agent asks, Leash decides curl -X POST https://leash.onrender.com/api/intent \ -H "x-agent-key: $LEASH_KEY" -H "content-type: application/json" \ -d '{"coin":"ETH","side":"long","leverage":3,"usd":1500,"reason":"Model sees a breakout"}' # → { "type": "filled" } inside your rules # → { "type": "approval" } waiting for your glasses # → { "type": "blocked" } broke a rule, never placed
